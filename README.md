# TickerWhy

TickerWhy is an unofficial redesign concept of the Google Finance AAPL news section that tells the reader why each article was collected for the company page and lets them flag ones that do not belong. Unofficial redesign concept, not affiliated with or endorsed by Google.

The LLM reads only the headline and the saved excerpt, and its answers are not guaranteed to be the same on every run; the cache is what a reviewer sees. Flags stay in the browser and nobody reviews them yet.

## News sources

Chosen on 16 Nov 2026 by opening each feed and trying an excerpt from up to 4 of its articles (details in `data/sources.json`). Financial and business sources come first, because the Apple product blogs I used before gave almost no earnings, analyst or stock-price news. All 8 link straight to the publisher and gave an excerpt for every article tried.

| Kind | Sources |
|---|---|
| Business and markets | CNBC (Top News, Earnings and Technology feeds), The Motley Fool, Fortune, Business Insider, BBC Business, The Guardian Business |
| Apple news sites | 9to5Mac, MacRumors |

Left out: Nasdaq.com AAPL news and Forbes (pages blocked, HTTP 403), MarketWatch (paywall), Yahoo Finance and Investing.com (pages could not be opened or were blocked), Business Insider Markets (links go to other sites), AppleInsider (blocked). Cult of Mac, Macworld, The Verge, TechCrunch, Engadget and The Guardian Technology were dropped to keep only two Apple sites.

## Technology stack

- Next.js 16 (App Router), React 19, TypeScript, Node.js 20.9 or later
- Plain CSS and a hand-drawn SVG chart, no UI or chart libraries
- Stock prices: Yahoo Finance public chart endpoint (unofficial, no key), fetched on the server
- News: 8 free RSS sources (`data/sources.json`), collected once a day by a GitHub Actions workflow at 05:00 UTC (midnight in New York). AAPL is a US stock, so each snapshot is named after the New York day that has just ended and is meant to hold one US day of news
- Excerpts: `@mozilla/readability` with `jsdom`, used only by the collector script
- LLM: Groq (`openai/gpt-oss-120b`) through its OpenAI-compatible API with a strict JSON schema, called only from the `/api/relevance` route

## Running or inspecting the work

**Without an API key:** run `npm install`, then `npm run dev`, and open http://localhost:3000. Nothing on the pages needs a key.

**Collecting news:** `npm run fetch-news` collects the New York day that has just ended (only 16 and 17 Nov 2026). `npm run fetch-news -- --dev` collects the last 24 hours into `data/news/dev.json`. Either run takes several minutes because every article page is opened once, with a pause in between.

**Checking the saved price data:** run `STOCK_FORCE_SAVED=1 npm run dev`. The page then skips the live fetch and shows `data/stock-fallback.json`, labelled "Saved data".

**With your own API key (to judge relevance and build the test list):**
1. Copy `.env.example` to `.env.local`.
2. Put your own key after `GROQ_API_KEY=`. Never commit `.env.local`.
3. Run `npm run dev`, then in a second terminal `npm run analyze-news`, then `npm run select-test-set`. Check `data/news/test-set.json` and edit it by hand if needed. It analyses articles that are not in the cache yet; delete the cache files to analyse all of them again.

**Switching model or provider:** change `LLM_BASE_URL` and `LLM_MODEL` in `.env.local`.

## Additional files

- `CLAUDE.md`: rules for AI coding agents working in this repo.
- `.env.example`: settings template with no real key.
- `data/sources.json`: the RSS sources, why each was chosen, and the rejected ones.
- `data/rules.json`: the collection rule words.
- `data/news/`: news snapshots (`dev.json` is a development sample, not part of the dataset).
- `data/news/test-set.json`: the test list the app shows (ids in display order) with the answer key (role, category, spy_type).
- `data/news/spy-articles.json`: the 2 planted spy articles, with `spy_type` and `expected_relevance`. These two fields are for checking answers only; they are never shown or sent to the LLM.
- `data/dev-google-news/`: the earlier Google News snapshot, its LLM cache and exclusion list, kept for the record only.
- `data/cache/`: cached LLM relevance judgements for evaluation, with the model name and time (hidden in the UI).
- `data/example-news.ts`: example articles (simulated), shown only if there is no snapshot.
- `.github/workflows/fetch-news.yml`: daily news fetch.
- `data/stock-fallback.json`: saved AAPL prices, refreshed with `npm run save-stock` while the app is running.
